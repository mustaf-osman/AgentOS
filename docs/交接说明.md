# AgentOS 交接说明

更新时间：2026-10-20。

## 产品定位

**最新定义见《产品定义与NewPulse参考.md》：这是通过自然语言直接操控电脑的小硬件，当前先完成电脑端软件，不实现硬件。科研提效是重点应用场景。后续开发以这一用户定义为准。**

以自然语言驱动研究资料处理、工具使用和可复现实验的智能体软件，核心接入 Qwen，面向“基于 Qwen 大模型的科研提效：认知增强与研发范式革新”方向。视觉继承 VeriFoundry；实现与数据目录独立。

本轮交付重点：真实文件、真实计算、真实工具日志，以及清楚可见的操作确认。ESP32 仅留扩展位置，不进行连接。

## 建议接续顺序

1. 当前已连接 AIPing 的 Qwen 模型。若切换到百炼，修改地址、模型和对应地域的凭据。继续检查实际使用中的工具失败、用户拒绝、模型限流与任务中断行为。
2. 选择一个具体研究场景和人工流程作对照，收集完成时间、结果质量与复现成功率。软件本身的工具日志不能当成科研结论的正确性证明。
3. 根据实际使用扩展 Windows 控件覆盖；若需要视觉定位或跨应用长流程，再评估官方 Qwen computer-use 项目。当前适配不支持所有应用。
4. 补上桌面安装版首次运行的数据导入/迁移，让开发版历史、模型设置可以明确迁入；继续完善运行环境迁移、权限隔离和任务恢复。
5. 用户明确要求后，再实现 ESP32 接入协议、通信和硬件验证；不要提前扫描串口或声称接入成功。

## 重要实现约束

- `data/settings.json` 含本机明文凭据，不能进入交接材料或版本库。
- 项目文件工具检查相对路径及符号链接；本机 Python 仍是当前用户权限，不具备 OS 沙箱隔离。
- 网页与资料文字作为不可信输入，不给予系统指令权限。
- 模型没有使用工具、没有完成计划或存在工具失败时，结果应显示“待复核”。流程完成也不等于研究结论已独立验证。
- 合成实验与真实硬件数据明确区分；没有标签不生成 F1。
- 启动器根据实例标识复用已有服务。端口冲突只更换本服务端口，不能结束未知进程。

详细运行方法、项目结构和能力边界见上级目录 README.md。

## Windows 桌面封装

已新增 Electron 桌面主进程 `electron/main.cjs`、AgentOS 图标 `build/agentos.ico`，以及安装构建脚本。桌面窗口复用 `public/` 聊天界面，Electron 主进程负责启动本地 API 服务；安装版在退出时停止自己启动的服务，开发版检测到现有 AgentOS 服务时会连接它而不重复启动。

已成功构建 Windows x64 NSIS 安装包 `dist/AgentOS-Setup-0.1.0.exe`（115,805,405 字节），并启动打包目录里的 AgentOS 桌面程序。后端、页面和 PowerShell 工具从 `app.asar.unpacked` 加载。桌面主进程支持单实例、复用健康的既有本机服务；安全 WebContents 配置禁用 Node 集成和弹窗导航，外链仅允许 HTTPS。

安装版默认把数据放在 Electron 用户数据目录，卸载不清除；开发版继续使用仓库 `data/`。为本机预览，可用 `AGENTOS_DATA_DIR` 指定现有数据目录，`AGENTOS_ELECTRON_PROFILE` 指定独立 Chromium 配置目录。安装版首次运行不会自动复制开发版资料及模型凭据，数据导入仍需补做。

构建命令：`npm install` 后 `npm run desktop:build`。Electron 内置 Node 24 运行后端，无需目标机器单独安装 Node。Python 与 Playwright 仍是可选外部能力；PDF 提取需要 Python/pypdf，公共网页研究需要 Playwright/Chromium。

尚未验证 NSIS 安装向导安装后的首次启动、Python/Playwright 跨机器依赖和用户数据迁移。当前打开的是 `dist/win-unpacked/AgentOS.exe`，不是已安装副本；实际用户数据迁移尚未执行。
